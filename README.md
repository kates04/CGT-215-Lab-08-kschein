This project was created using C++, SFML, and SFPhysics. This is a simple Duck Hunter game where the player uses a crossbow with 5 arrows to shoot ducks that spawn in every second and move accross the screen. This project tracks the number of arrows left in the bottom left and the score, in the bottom right, which increases by 10 everytime a duck is hit with an arrow. After all 5 arrows have been used, the game will display a Game Over screen that will remain until the player presses the space button.
